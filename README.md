# ATM-Management-System
A GUI-based ATM Interface System developed using Java Swing. The project simulates basic ATM operations through an interactive graphical user interface, including user validation, account navigation, and transaction handling.
The project is designed to simulate some basic ATM functions. Users can log in to their account and perform different banking operations.

## Features
* Login to an account
* Check account balance
* Deposit money
* Withdraw money
* Transfer money
* View account information
* Perform basic ATM transactions

## Technologies Used
* Java
* Object-Oriented Programming (OOP)

## How to Run
1. Download or clone the repository.
2. Open the project in a Java IDE.
3. Make sure Java is installed on your computer.
4. Run the main class.
5. Follow the instructions shown in the program.

## About the Project
We made this project to practice the OOP concepts we learned in Java and to understand how those concepts can be used to build a simple banking/ATM system.
This project was created for academic purposes as part of our OOP Lab course.
